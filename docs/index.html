💾 Tự động sao lưu model

  • Lưu bản dự phòng theo chu kỳ 5–30 phút, chỉ khi model có thay đổi.
  • Ưu tiên lúc bạn dừng tay, không làm giật khi đang vẽ.
  • SketchUp văng hoặc treo: lần mở sau HT Ally hỏi bạn có mở bản sao lưu gần nhất không.

📉 Lưu file ở phiên bản thấp

  • Hạ file xuống SketchUp 2020 để gửi cho khách hoặc đồng nghiệp dùng bản cũ.
  • File đang mở giữ nguyên, không lo ghi đè.

🔄 Cài lại plugin trên máy mới

  • Đăng nhập Google, bấm một nút để cài lại các plugin còn thiếu.
  • Chỉ lưu mã plugin và số phiên bản, không lưu file hay model. Tắt được bất cứ lúc nào.

🌙 Giao diện sáng / tối

  • Dịu mắt khi làm việc ban đêm.

Cài đặt trong 3 bước

  1. Bấm Tải HT Ally và lưu file .rbz.
  2. Trong SketchUp: Window ▸ Extension Manager ▸ Install Extension, chọn file vừa tải.
  3. Khởi động lại SketchUp, rồi mở HT Ally từ thanh công cụ (nếu chưa thấy, bật trong View ▸ Toolbars).

Nếu SketchUp hỏi về extension chưa ký (unidentified extension), chọn Yes để cho phép tải.

Câu hỏi thường gặp

HT Ally có miễn phí không?

HT Ally miễn phí. Các plugin HT hiện cũng đang miễn phí. Plugin có phí sau này sẽ có dùng thử trước khi mua.

Dùng được trên SketchUp nào?

SketchUp 2020 trở lên, trên Windows.

HT Ally lưu thông tin gì của tôi?

Chỉ tên, email Google để quản lý bản quyền, và (nếu bạn bật) danh sách mã plugin đã cài. Xem chi tiết ở chính sách riêng tư.

Tự động sao lưu không chạy?

SketchUp chỉ cho sao lưu model đã được lưu ít nhất một lần. Hãy lưu model (Ctrl+S) rồi thử lại.
